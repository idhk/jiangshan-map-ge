# 格鲁吉亚历史版 · 第一框架（v0.1）

> 目标：沿用「江山时序」的 **时代 → 版图阶段（phase / snap）→ 里程碑（milestone）** 结构，
> 做一个格鲁吉亚（Sakartvelo）的历史时序地图。本版只有**时间轴与国界规格**，还没有任何几何（polygon）。

- 数据骨架：[`ge_dynasty_data.js`](./ge_dynasty_data.js) → `window.GE_DYNASTY_DATA`（schema 与 `js/map_data.js` 的 `DYNASTY_DATA` 一致）
- 规模：**14 个时代 · 48 个版图快照 · 74 个里程碑**，覆盖约前 600 年 — 2026 年
- 每个 phase 都带 `borderNote`：这一张快照「应当画哪几块政权、边界大致在哪」，是后续绘图的规格书

## 2. 国界绘制策略（第二步要做的事）

1. **三层精度**，按时代切换数据源：
   - 1886 年以后：用 [CShapes 2.0](https://icr.ethz.ch/data/cshapes/)（国家边界逐年数据）+ 俄帝国省界 → 精度高
   - 中世纪（约 800–1800）：参考 [Euratlas 历史地图](https://www.euratlas.net/history/europe/index.html)（世纪切片）与 Wikimedia 的格鲁吉亚历史地图，手绘
   - 古代（前 600–800）：沿山脊 / 河谷画「自然地形边界」，`borderNote` 中写明为示意，UI 中用虚线
2. **以自然地形为骨架**：大高加索主脊（北界）、利希山 / 苏拉米山（东西分界）、小高加索与乔鲁赫河谷（南界）、库拉河、里奥尼河。复用仓库已有「边界贴合地形」的做法（见提交 `d12b4f2`）。
3. **争议区单独图层**：阿布哈兹、南奥塞梯、洛里中立区、扎卡塔拉、阿尔达汉 —— 用斜线 + 标注「事实控制 / 国际承认」，不和主权色混画。
4. 现代底图：[Natural Earth](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/) admin-1（格鲁吉亚 9 州 + 2 自治共和国 + 第比利斯），用作「X 光透镜」的现代对照层。

## 3. 需要你拍板的问题

- **起点**：从前 600 年科尔基斯开始，还是从前 299 年伊比利亚立国开始？（目前取前 600）
- **视野范围**：地图框只看今格鲁吉亚 + 周边，还是把亚美尼亚、阿塞拜疆、北高加索、土耳其东北部也画成政权块？（塔玛尔时代版图需要后者）
- **界面语言**：中文为主，是否需要格鲁吉亚语（ქართული）地名并列？
- **敏感区表述**：阿布哈兹 / 南奥塞梯采用「国际承认为格鲁吉亚领土 + 事实控制」的双标注（目前方案）
